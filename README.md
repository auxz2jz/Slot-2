# Relic of Emberwood — Four Era Fidelity Lab

Four original Emberwood gameplay/graphics studies targeting the presentation and control feel of four classic action-adventure eras:

- NES I: native 256×240 presentation, 16×16-style sprites, four-direction room movement and sword thrust combat.
- NES II: 256×240 side-view action, 16×32-style actor proportions, acceleration, crouch, jumping and horizontal sword combat.
- SNES: native 256×224 presentation, richer layered pixel art, smooth diagonal motion, sword charge/spin and interactive field objects.
- N64: low-poly 3D scene with low-resolution filtered textures, follow camera, lock-on strafing, rolling/evading and animated sword combat.

All character, enemy, environment and UI art in this demo is original to Relic of Emberwood.
